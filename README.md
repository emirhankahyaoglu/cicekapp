# 🌼 Papatya Sevgi Oyunu

Sevgiliniz için özel olarak hazırlanmış romantik bir papatya falı uygulaması.

## Özellikler

- ❤️ Her tıklamada bir yaprak kopar ve düşer
- 💕 "Seviyor" / "Sevmiyor" ruleti
- 🎯 Son yaprak her zaman "Seviyor" çıkar
- 🌸 Her oyunda 6-12 arası rastgele yaprak sayısı
- ✨ Güzel animasyonlar ve renkler

## Kurulum

1. Bağımlılıkları yükleyin:
```bash
npm install
```

2. Uygulamayı başlatın:
```bash
npm start
```

3. Tarayıcınızda otomatik olarak açılacaktır: http://localhost:3000

## Nasıl Oynanır?

1. Ekrana tıklayın
2. Her tıklamada bir yaprak kopar ve düşer
3. Çiçeğin üstünde "Seviyor" veya "Sevmiyor" yazısı belirir
4. Son yaprak her zaman "Seviyor ❤️" olacaktır
5. Tüm yapraklar bitince tekrar oynamak için tıklayın

## Sevgilinize Hediye Etmek İçin

Uygulamayı build edin:
```bash
npm run build
```

Build klasörünü herhangi bir web sunucusuna yükleyebilir veya GitHub Pages gibi ücretsiz hosting servislerinde yayınlayabilirsiniz.
